# Deep Learning Practice

This repository contains my deep learning practice projects using Python, TensorFlow, Keras, NumPy, and Pandas.

## Projects

### 1. Thoracic Surgery Survival Prediction
- Dataset: ThoraricSurgery3.csv
- Model: Sequential Neural Network
- Input features: 16
- Hidden layer: Dense (30 neurons)
- Output layer: Sigmoid
- Optimizer: Adam
- Loss function: Binary Crossentropy

### 2. Pima Indians Diabetes Prediction
- Dataset: Pima Indians Diabetes
- Model: Sequential Neural Network
- Input features: 8
- Hidden layers: Dense (12), Dense (8)
- Output layer: Sigmoid
- Optimizer: Adam
- Loss function: Binary Crossentropy
- Epochs: 100
- Batch size: 5
